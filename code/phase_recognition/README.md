# Macroscopic phase recognition

This folder will contain the TeCNO baselines of the paper (Sec. IV-A, IV-C):

- Stage 1: ResNet-50 frame classifier;
- Stage 2: causal MS-TCN;
- the cyclic leave-one-out protocol (Experiment A) and the zero-shot porcine run (Experiment B);
- confidence-gated view selection and static fusion;
- evaluation (accuracy, macro-F1, Edit, F1@k);
- the per-frame test predictions of all models.

The code and predictions will be added before publication.
